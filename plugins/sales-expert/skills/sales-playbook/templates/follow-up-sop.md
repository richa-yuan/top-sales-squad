# 跟进节奏 SOP

**客户**：
**当前阶段**：线索 / 初步接触 / 需求确认 / 方案 / 报价 / 谈判 / 签约 / 交付 / 续约
**决策周期**（估算）：短（< 1 个月）/ 中（1–3 个月）/ 长（> 3 个月）

---

## 一、跟进铁律

1. **每次跟进必须带新信息**——新数据、新案例、新视角、新资料。重复"跟进一下"是消耗信任最快的方式。
2. **节奏按决策周期定**，不按你的心情定：
   - 短周期：7–10 天一次
   - 中周期：2–3 周一次
   - 长周期：30 天一次，但每次必须带实质内容
3. **不要在没有信息增量时硬约见面**。宁可发一封有价值的行业材料，也别约一顿没有议题的饭。
4. **每次沟通都要推进一个具体的动作**（给材料 / 约时间 / 请他确认 / 请他引荐），而不是"保持联系"。
5. **客户不回 ≠ 拒绝**。超过三次无回应，换渠道（换人接触、寄材料、走第三方）。

## 三、各阶段的推进动作

| 阶段 | 目标 | 关键动作 | 通过标准（进入下一阶段的条件） |
|---|---|---|---|
| 线索 → 接触 | 见到人 | 转介绍 / 个性化触达 / 行业社群 | 对方愿意聊 20 分钟 |
| 接触 → 需求确认 | 拿到场景和数字 | 诊断提问 | 拿到 3 个量化数字 |
| 需求确认 → 方案 | 客户认价值 | 价值测算 + ROI | 客户内部传阅你的材料 |
| 方案 → 报价 | 摸清预算与流程 | 报价 + 预算路径确认 | 拿到预算区间与采购形式 |
| 报价 → 谈判 | 处理异议 | 异议话术 + 证据 | 异议被消化，对方主动谈内部流程 |
| 谈判 → 签约 | 拿到合同 | 合同条款 + 付款条件 | 合同发出 |
| 签约 → 交付 | 顺利交付 | 项目启动会 | 验收 |
| 交付 → 续约 | 续约增购 | 价值复盘报告 | 续约 / 扩容 |

---

## 四、无回应时的升级路径

| 次数 | 动作 |
|---|---|
| 第 1 次无回应 | 换渠道触达（邮件 → 电话 → 微信 → 换人） |
| 第 2 次无回应 | 发一份不带销售目的的高价值材料（行业报告、案例集） |
| 第 3 次无回应 | 走第三方：合作伙伴、行业协会、原厂高层引荐 |
| 仍无回应 | 降低优先级至季度触达，把精力转向新线索 |

**关键**：不要在同一个渠道上重复三次。
