# 定价与报价原则

## 一、三层定价模型

任何报价都要能回答这三个问题，缺一层价格就是拍脑袋。

```
成本底价  →  价值锚点  →  市场校验
（我至少要收多少）（客户觉得值多少）（同行大概多少）
```

- **成本底价** = 直接成本 + 分摊成本 + 交付成本 + 风险准备金 + 目标毛利
- **价值锚点** = 客户年化收益 ÷ 客户可接受的支付比例（通常 5%–20%，越难替代可越高）
- **市场校验** = 客户替代方案的成本（人工做、外包、自研、竞品报价）

**三者的关系**：成本决定"不能低于多少"，价值决定"可以要到多少"，市场决定"客户不会跑"。

---

## 二、价值锚点的算法

```
客户年化收益 = 节省人力成本 + 减少错误/损失 + 缩短周期带来的增量 + 规避风险敞口
客户可接受价格 = 年化收益 × 支付意愿比例（10%–20% 为常见区间，高价值独占场景可更高）
```

**基线口径必须客户确认**，不能替客户估。基线错了，后面全错。基线三个必问数：
1. 这个环节现在的**规模**（年产量 / 订单量 / 客户数 / 数据量）
2. 现在的**单次成本或单件成本**
3. 现在的**错误率或耗时**

---

## 三、三档报价结构

永远给三档，不要给一档。给一档客户只能回答"买/不买"；给三档客户在选。

| 档位 | 作用 | 设计要点 |
|---|---|---|
| **入门版** | 让他敢开始 | 只解决一个最痛的点，价格低到决策门槛以下（通常为首年 20%–40%） |
| **标准版（主推）** | 承接真实需求 | 覆盖主场景 + 集成 + 支持，标注"最受欢迎"，占 50%–60% 成交 |
| **旗舰版** | 做锚定 | 含平台化/私有化/定制/SLA，让标准版显得划算（通常是标准版的 2–3 倍） |

**进阶设计**：
- 旗舰版的定价锚点是"如果不买旗舰版会出什么事"，不是"我要赚多少"
- 入门版要**故意在能力上留一个缺口**（客户很快会需要进阶），这样升级路径自然存在
- 三档之间差异要在**客户能感知的功能/服务/保障**上，不能只在参数表上

## 四、折扣授权梯度

把折扣规则预先定死，避免一线现场乱承诺。

| 折扣幅度 | 审批人 | 必须换回的条件 |
|---|---|---|
| ≤ 5% | 销售自主 | 无（或仅缩短交付周期） |
| ≤ 10% | 销售主管 | 预付 ≥ 30% / 合同期 ≥ 2 年 / 案例授权 |
| ≤ 20% | 销售总监 | 预付 ≥ 50% / 合同期 ≥ 3 年 / 独家条款 / 批量承诺 |
| > 20% | 分管副总 | 需战略理由备案（进入新市场、标杆客户、战略卡位） |

**配套规则**：
- 折扣必须**换回条件写进合同**，不是口头承诺
- 二次报价时，折扣幅度**递减**（10% → 5% → 2%），传递"到底了"
- 折扣与**授权期限**绑定："此折扣有效期至 X 月 X 日"，制造决策紧迫感

## 五、TCO（总拥有成本）

客户和采购真正比的是 TCO，不是首年报价。

```
TCO = 采购价 + 实施/集成费 + 内部投入（IT + 业务方工时）
    + 运行成本（算力/许可/维护/耗材/服务费）
    + 迁移与切换成本 + 退场成本 − 残值
```

**最常被漏算的一项是内部工时**。帮客户算出来，这是最有说服力的一张纸。

---

## 六、涨价与锁价条款

长期合同必须处理价格风险：

| 条款 | 写法 |
|---|---|
| 锁价期 | 合同总价锁定，变更走变更单另计 |
| 年度调价 | 每年不高于 X%（建议 ≤ 5%，且不高于 CPI） |
| 续费涨价 | 续费价涨幅上限写死（建议 ≤ 8%/年，或与第一年价挂钩） |
| 用量计费阶梯 | 阶梯区间与单价写死，避免"按原价 × 数量" |
| 汇率/原材料 | 明确是否联动、触发阈值、调整幅度上限 |

## 七、常见定价错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 按成本定价 | 客户不为你的成本买单 | 按客户收益定价 |
| 按竞品定价 | 永远打价格战，毛利被击穿 | 按客户收益定价，竞品只做校验 |
| 首年免费换后续高价 | 续约时爆发冲突 | 免费换的是承诺，不是单年价格 |
| 折扣换不回东西 | 客户学会压价 | 每次让步绑定交换条件 |
| 用量成本没算重试与冗余 | 上线后毛利崩塌 | 按生产环境的 1.5–3 倍用量估算 |
| 实施服务不收费 | 毛利被交付吃光 | 一次性实施费单列 |
| 第二年价格没锁 | 续费时被宰或被拖 | 合同中写明续费涨幅上限 |
