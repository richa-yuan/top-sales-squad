# 渠道与价盘规则速查

> 详细模板见 `templates/channel-policy.md`。此文件是速查规则。

## 一、价盘（先定死，再招人）

```
建议零售价 SRP  ← 客户心里的锚，所有折扣的参照
   ↓
渠道供货价
   ↓
渠道毛利 = (SRP − 供货价) ÷ SRP
```

| 渠道毛利率区间 | 结果 |
|---|---|
| < 15% | 渠道不认真推，只压货 |
| 20%–35% | **健康区间** |
| > 40% | 窜货套利风险高 |

**分渠道价必须同时定义**：直销价、经销价、代理价、大客户价，各自的适用条件与冲突裁决规则。

**区域保护**：范围 + 期限必须写明。独家代理要写业绩条件，未达标如何收回。

---

## 二、返利政策

| 设计项 | 规则 |
|---|---|
| 计提基数 | **优先按回款额**（避免压货）；次选开票额；**不建议出货额** |
| 返利形式 | 现金返利为主 + 返货为辅；MDF 专项用于市场活动 |
| 阶梯档数 | 不超过 3 档（渠道算不明白就等于没有） |
| 兑现条件 | 退货扣减、发票合规、期限（建议 6–12 个月过期作废） |
| 兑现速度 | **越快越可信**；拖过 3 个月，渠道会认定政策是画饼 |
| 跳档规则 | 写清整体跳档还是增量跳档（增量跳档对渠道更友好） |

## 三、渠道商筛选

**三问筛选法**（答不上来的不要签）：
1. 他服务的**三个具体客户名**是什么？
2. 他现在代理的**竞品**是谁、用的什么打法？
3. 他愿意为你的品牌**投入什么资源**（人、钱、场地）？

**三条红线**：
- 只压价囤货不做动销的
- 老板不亲自管、把渠道当副业的
- 方法不可迁移的竞品老渠道（会把你的打法带歪）

---

## 四、招募漏斗

```
目标名单 → 触达 → 意向确认 → 资质评估 → 商务谈判 → 签约 → 首单 → 出货 → 动销
```
- **签约后 90 天是生死线**：首单要快、出货要快、要有第一个动销案例
- **签了不动销的渠道 = 没签**，还占着区域，是负资产

---

## 五、窜货与价格治理

| 手段 | 有效性 | 投入 |
|---|---|---|
| 一物一码 / 序列号追溯到终端 | 高 | 需系统 |
| 返利与流向数据挂钩 | 高 | 中 |
| 数字化订货（扫码订货、终端可查） | 高 | 中高 |
| 差异化包装/渠道专供型号 | 中高 | 低 |
| 区域与客户类型切割 | 中 | 低 |
| 价格管控协议 + 违约罚则 | 中 | 低 |
| 窜货举证与裁定机制 | 中 | 低 |

**处罚节奏**：第一次整改 + 警告 → 第二次降级/扣返利 → 第三次取消授权。
**第一次就重罚，渠道体系会立刻冷掉。**

---

## 六、渠道与直销冲突

- **归属规则先定**：什么客户归渠道、什么归直销、重叠时谁裁决
- **报备保护期**：渠道报备客户后给 6–12 个月保护期
- **协同而非对立**：直销帮渠道攻大客户，渠道帮直销补覆盖

---

## 七、渠道赋能与考核

| 层级 | 标准 | 资源配给 | 返利率 |
|---|---|---|---|
| 核心 | 覆盖重点区域 + 稳定动销 + 团队投入 | 专属支持、联合营销、样机 | 最高 |
| 重点 | 稳定出货 + 有明确行业资源 | 常规支持、专项激励 | 较高 |
| 普通 | 有基础覆盖能力 | 标准支持 | 标准 |
| 观察 | 试单阶段 | 政策 | 无 |

**考核指标**：动销率（出货/进货）、回款率、活跃客户数、新客开发数、跨区域窜货次数。
