# 销售打法库 · Playbook

一套沉淀下来的销售作战资产。**这个库的价值不在于"听起来专业"，而在于拿出来的表格和话术能直接用。**

## 怎么用

```
1. 定位卡点     → references/ 中的对应参考文档
2. 填模板       → templates/ 中复制对应模板
3. 填话术       → references/objection-handling.md 查四条层拆解 + 对应回应
4. 定节奏       → templates/follow-up-sop.md
5. 收尾复盘     → templates/win-loss-review.md
```

**硬性要求**：
- 从 `templates/` 复制模板再填，不要凭记忆重写结构——结构的完整性就是专业度
- 话术必须是**可以直接念出来的原话**，不是"应当建立深度信任"这类废话
- 凡是数字，必须标来源：客户提供 / 公开信息（注明来源与日期）/ 假设（明确标注）
- 信息缺口优先用一次 AskUserQuestion 补齐最关键的 3 项，不要连环追问

## 通用铁律

1. **一次只解决一个卡点。** 线索层、需求层、价值层、信任层、决策层、商务层、竞争层——先定位再开打。
2. **让价必须换条件。** 降价换预付、换账期、换范围、换期限、换案例授权。单方面降价是自伤。
3. **证据先于话术。** 客户不信你的时候，你缺的是证据不是表达技巧。
4. **甲方视角必须过一遍。** 任何价格与承诺，先推演买方会怎么质疑、怎么砍、怎么比。
5. **不承诺没把握的事。** 交付、精度、效果、收益，写进合同前必须与技术/交付确认。
6. **未知就写未知。** 编造行业数据、竞品价格、客户背景是最严重的失职。
